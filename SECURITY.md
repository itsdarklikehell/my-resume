# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

Als je een beveiligingskwetsbaarheid vindt, open dan een issue in de GitHub repository.

We doen ons best om kwetsbaarheden zo snel mogelijk te verhelpen.

If you find a security vulnerability, please open an issue in the GitHub repository.

We will do our best to fix vulnerabilities as soon as possible.

Si vous trouvez une vulnérabilité de sécurité, veuillez ouvrir un ticket dans le dépôt GitHub.

Nous ferons de notre mieux pour corriger les vulnérabilités dans les plus brefs délais.

Wenn Sie eine Sicherheitslücke finden, eröffnen Sie bitte ein Ticket im GitHub-Repository.

Wir werden unser Bestes tun, um Sicherheitslücken so schnell wie möglich zu beheben.
